Contenedores y Grid

Container · row · col · 12 columnas · gutters · breakpoints · CSS Grid

El patrón que organiza una página

container centra y limita el ancho; container-fluid ocupa todo el disponible. Dentro, row crea una fila Flexbox y col son sus hijos. No es CSS Grid nativo: Bootstrap usa Flexbox para sus columnas.

<div class="container"><div class="row g-4">
 <article class="col-12 col-md-6 col-lg-4">Curso</article>
</div></div>
1–12 móvilmd: 6lg: 4

12 columnas y mobile-first

col-12 es ancho completo; col-md-6 ocupa media fila desde 768px; col-lg-4, un tercio desde 992px. Sin número, col reparte espacio automáticamente. g-4 representa el espacio entre columnas: gutter.

Práctica

  1. Construye cuatro cards con col-12 col-sm-6 col-lg-3.
  2. Cambia el viewport entre 375, 768 y 1280px.
  3. Explica por qué CSS Grid nativo sería preferible para áreas con filas explícitas.

Comprobación: 1, 2 y 4 cards por fila, sin media queries propias.

Error habitual: poner col sin row, o confundir este grid Flexbox con display:grid.
