Taller guiado: landing DevAcademy

Construirás una landing por incrementos. No copies una solución final: en cada etapa escribe, prueba y compara con el resultado esperado.

1 Base · 2 Navegación · 3 Hero · 4 Cursos · 5 Ventajas · 6 Formulario · 7 Footer · 8 Responsive

1. Preparar los archivos

Objetivo: una página funcional antes de diseñar. Crea index.html y styles.css; enlaza Bootstrap primero y tu hoja después.

<main><!-- aquí construiremos la landing --></main>
<link rel="stylesheet" href="bootstrap.css">
<link rel="stylesheet" href="styles.css">

2. Navegación

Aplica navbar, marca y tres enlaces. Usa el bundle para el collapse móvil. Comprueba: a 375px el toggler abre; con Tab se ve el foco.

3. Hero

Usa container py-5 text-center para estructura inicial. Tu CSS propio decide la identidad: fondo, imagen, altura y tipografía.

<section class="hero-devacademy"><div class="container py-5 text-center">
 <h1>Aprende para crear</h1><p>Cursos prácticos.</p>
 <a class="btn btn-primary" href="#cursos">Ver cursos</a>
</div></section>

4. Catálogo de cursos

Reutiliza row g-4 y col-12 col-md-6 col-lg-4. Dentro, cada curso es un article.card. Comprueba: una, dos y tres columnas según viewport.

5–7. Ventajas, formulario y footer

Para ventajas usa tres columnas sencillas; para contacto, labels y form-control; para footer, una container con enlaces reales. No conviertas cada bloque en una card si no representa contenido independiente.

8. Comprobación responsive

  1. Móvil 375px: menú, CTA y formulario no desbordan.
  2. Tablet 768px: catálogo en dos columnas.
  3. Escritorio 1280px: tres cursos, texto legible y aire visual.
  4. Teclado: foco visible, orden lógico y labels asociados.
  5. DevTools: identifica una regla Bootstrap y una propia en cada sección.

Entrega: enlaza tu repositorio o carpeta y explica tres decisiones CSS que Bootstrap no tomó por ti.
