Un recorrido práctico para pensar, organizar y probar una web antes de escribir HTML y CSS. No necesitas saber diseño: vamos a construir paso a paso un CV digital sencillo.

Penpot no sustituye a HTML y CSS. Nos ayuda a pensar qué queremos construir antes de empezar a programarlo.

Todo el manual gira alrededor de un único proyecto: un CV digital. No buscamos una web espectacular ni un sistema profesional completo. Buscamos comprender el proceso y llegar a una referencia clara para empezar HTML y CSS.

Cómo estudiar

Lee un capítulo, realiza la práctica en Penpot y después continúa. No importa memorizar botones: importa entender qué problema resuelve cada herramienta.

1. Antes de programar: pensamos el diseño

Qué vamos a aprender

Por qué merece la pena decidir antes de abrir el editor de código.

El problema

Si empezamos HTML sin saber qué información mostrar, qué es importante o cómo se verá en móvil, es habitual rehacer estructura y CSS varias veces.

Ejemplo en nuestro CV

Una persona debe reconocer rápidamente quién eres, qué haces, qué proyectos has creado y cómo puede contactarte. Ese orden se decide antes que los colores.

  1. Escribe una frase: «Quiero que una persona conozca mi perfil y pueda contactar conmigo».
  2. Anota: nombre, profesión, descripción, formación, proyectos y contacto.
  3. Ordena ese contenido por importancia.

Error frecuente

Elegir una paleta o escribir etiquetas HTML antes de saber qué necesita la persona que visita la web.

Práctica

Sin abrir Penpot, redacta el objetivo de tu CV y elige sus tres contenidos imprescindibles.

Diseñar no retrasa la programación; evita programar decisiones aún no tomadas.

2. Qué es Penpot y qué nos aporta

Penpot es una herramienta para diseñar interfaces y crear prototipos. Sirve para representar, organizar y probar una web antes de implementarla.

En Penpot

Decidimos estructura, pantallas, aspecto visual y navegación simulada.

En HTML, CSS y JavaScript

Construimos la web real: semántica, estilos, responsive, accesibilidad y comportamiento.

Práctica

Crea un archivo llamado CV-Nombre-Apellido. No intentes diseñarlo entero todavía: primero conoceremos sus piezas.

3. Conocer la interfaz sin miedo

Al abrir un archivo encontrarás una zona central de trabajo, herramientas para crear elementos, el panel de capas y el panel de propiedades. No necesitas dominar todo hoy.

  • Herramientas: crear, seleccionar, escribir texto o dibujar formas.
  • Panel de capas: ver qué elementos existen y cómo se organizan.
  • Propiedades: cambiar tamaño, posición, color o texto.
  • Zoom: acercarte para trabajar y alejarte para revisar.

Práctica

Crea un archivo, prueba el zoom y localiza el panel de capas. Después crea una forma y observa sus propiedades.

4. El lienzo y los Boards

El lienzo es la mesa de trabajo. Un Board es una pantalla o vista que colocamos sobre esa mesa.

LIENZO
├── CV - Mobile
└── CV - Desktop

No diseñamos la web directamente sobre el lienzo: diseñamos dentro de Boards.

BoardRectángulo
Representa una pantalla o vista.Es una forma visual.
Puede ser el CV móvil, desktop o detalle de proyecto.Puede ser un fondo, tarjeta, botón o cabecera.

Regla: Board = pantalla. Rectángulo = pieza visual. El propio Board ya es la pantalla: no crees un rectángulo blanco dentro para simularla.

  1. Localiza la barra de herramientas y selecciona Board.
  2. Haz clic y arrastra sobre el lienzo para crear el área de la pantalla.
  3. En el panel de propiedades, indica un tamaño móvil aproximado.
  4. En el panel de capas, cambia el nombre a CV - Mobile.
  5. Más adelante crearás CV - Desktop del mismo modo.

Qué deberías ver

Page 1
└── CV - Mobile

El Board aparece como una capa dentro de la página. Todo lo que diseñes para el CV móvil deberá quedar sangrado dentro de él.

Si no te sale

Si creaste una forma pequeña en vez de una pantalla, deshaz la acción y comprueba que has seleccionado Board, no Rectángulo. No crees un Board para Header, Proyectos o Footer: para nuestro CV, 1 Board = 1 pantalla o vista.

5. Capas: cómo se organiza el diseño

Cada elemento que creas aparece como una capa. El panel de capas muestra qué hay en el diseño, en qué orden está y qué contiene a qué.

CV - Mobile
├── Header
├── Quien-soy
├── Formacion
├── Proyectos
├── Contacto
└── Footer

Nombra las capas según su función: Header, Foto, Nombre o Boton-Proyectos. Evita Rectangle 1, Text 27 y Group 14.

  1. Crea un rectángulo y un texto dentro del Board.
  2. Localízalos en el panel de capas.
  3. Renómbralos Header y Nombre.
  4. Comprueba que aparecen sangrados dentro de CV - Mobile.

Error frecuente

Un botón puede parecer estar dentro del Board y, sin embargo, estar fuera en el panel de capas. La posición visual no garantiza la estructura.

6. Textos, rectángulos e imágenes

Con tres piezas ya podemos construir un wireframe: texto para comunicar, rectángulos para bloques y botones, e imágenes para la fotografía o proyectos.

Texto

En la barra de herramientas selecciona Texto, haz clic dentro de CV - Mobile y escribe Laura Martín. Desde propiedades puedes cambiar su tamaño; la tipografía definitiva puede esperar.

Rectángulos

Selecciona Rectángulo, arrastra dentro del Board y crea una franja para Header. Úsalos también para tarjetas y botones. En un wireframe pueden ser grises: muestran estructura, no decoración.

Imagen

Usa la opción de insertar imagen, elige una foto de perfil y redimensiónala desde sus controles. Si quieres un recorte circular, usa una forma como máscara solo si esa opción ya te resulta familiar; si no, deja una imagen rectangular.

Qué deberías ver

CV - Mobile
├── Header
├── Nombre
└── Foto

Son tres capas distintas dentro del Board. Renómbralas para no depender de nombres automáticos.

Práctica

En el Board móvil crea Header, escribe tu nombre y añade una foto provisional. Renombra sus capas.

7. Posición, X/Y y líneas de alineación

Al mover un elemento, Penpot muestra líneas rosas, centros y cruces de referencia. Sirven para alinear bordes o centros sin hacerlo a ojo.

  • Líneas rosas: relaciones de alineación con otros elementos.
  • Cruces y centros: puntos geométricos de referencia.
  • X e Y: posición del elemento dentro de su contenedor.

X e Y no son márgenes. Son coordenadas: dicen dónde está una pieza, no el espacio que debería existir en una web terminada.

  1. Crea dos rectángulos de igual tamaño.
  2. Arrastra el segundo hasta que aparezcan referencias.
  3. Alinea sus bordes superiores y observa cómo cambian X e Y.

Práctica

Alinea el nombre, profesión y foto de tu CV. Revisa el resultado alejado, no solo al hacer zoom.

8. Grupos y relación padre-hijo

Un elemento padre contiene otros elementos. Los elementos contenidos son sus hijos. Los hijos que comparten padre son hermanos.

CV - Mobile          ← padre
├── Header            ← hijo
├── Quien-soy         ← hijo
└── Footer            ← hijo

Un Board puede ser padre y un grupo también puede serlo.

Un grupo reúne varios elementos para moverlos y organizarlos como una unidad. Grupo = organizar.

Titulo-Quien-soy
├── Fondo
└── ¿Quién soy?
  1. Crea un rectángulo y un texto ¿Quién soy? dentro de CV - Mobile.
  2. Selecciona primero el fondo y, manteniendo pulsada Shift, selecciona el texto.
  3. Usa Ctrl + G en Windows/Linux o Cmd + G en macOS.
  4. En el panel de capas, renombra el grupo Titulo-Quien-soy.
  5. Muévelo y después edita solo el texto: agrupar no fusiona.

Qué deberías ver

Titulo-Quien-soy       ← padre
├── Fondo                ← hijo
└── ¿Quién soy?          ← hijo

El grupo es el padre; fondo y texto siguen siendo editables. Al mover el grupo se mueven todos sus hijos.

Si no te sale

Si Fondo y el texto aparecen al mismo nivel que CV - Mobile, no están dentro del grupo. Selecciónalos de nuevo y agrúpalos; después comprueba el sangrado del panel de capas.

9. Empezamos nuestro CV móvil

Ahora unimos las piezas. Trabajaremos manualmente con grupos, alineación y posición. Todavía no usaremos Layout.

  1. En CV - Mobile, crea un Header sencillo.
  2. Crea el título ¿Quién soy? con fondo y agrúpalo.
  3. Añade foto, nombre, profesión y una descripción de dos líneas.
  4. Deja espacio para botonera, formación, proyectos, contacto y Footer.
  5. Renombra cada capa o grupo cuando lo crees.

Qué debes observar

El objetivo no es que quede definitivo. Debe entenderse el orden: presentación, contenido profesional, proyectos y contacto.

Práctica

Aléjate con el zoom. En cinco segundos deberías identificar el nombre, profesión, proyectos y contacto.

10. Primero un botón; después, una botonera

Ya sabes que un Board representa una pantalla y un grupo reúne elementos relacionados. Vamos a construir el primer botón sin Layout: solo con un rectángulo, un texto, alineación y un grupo.

La estructura que buscamos

CV - Mobile                 ← Board
├── Presentacion
└── Boton-Proyectos         ← grupo
    ├── Fondo               ← rectángulo
    └── PROYECTOS           ← texto

El Board es la pantalla. Boton-Proyectos es un grupo. Fondo es un rectángulo y PROYECTOS es un texto. No creamos un Board para cada botón, sección o tarjeta.

Práctica: crear Boton-Proyectos

  1. Paso 1. Crea un rectángulo y renómbralo Fondo.
  2. Paso 2. Crea el texto PROYECTOS.
  3. Paso 3. Coloca visualmente el texto sobre el rectángulo.
  4. Paso 4. Selecciona Fondo y PROYECTOS.
  5. Paso 5. Usa las herramientas de alineación para centrar el texto horizontal y verticalmente respecto al rectángulo.
  6. Paso 6. Agrupa ambos elementos con Ctrl + G.
  7. Paso 7. Renombra el grupo Boton-Proyectos.
  8. Paso 8. Mueve el grupo completo y comprueba que fondo y texto se desplazan juntos.

Qué ocurre en las capas

El rectángulo no contiene al texto. Son hermanos dentro del grupo: el grupo es el padre; Fondo y PROYECTOS son hijos.

Boton-Proyectos
├── Fondo
└── PROYECTOS

No intentes construirlo así: Fondo → PROYECTOS. Un rectángulo simple es una pieza visual, no el contenedor estructural que necesitamos.

Crear la botonera

  1. Duplica Boton-Proyectos.
  2. Cambia el texto por FORMACIÓN.
  3. Renombra el nuevo grupo Boton-Formacion.
  4. Selecciona ambos botones y crea el grupo Botonera.
  5. Colócalos manualmente uno debajo de otro.
Botonera
├── Boton-Proyectos
│   ├── Fondo
│   └── PROYECTOS
└── Boton-Formacion
    ├── Fondo
    └── FORMACIÓN

Qué deberías ver

En el panel de capas, Botonera contiene dos grupos de botón. Colócalos manualmente uno debajo de otro; todavía no conviertas la Botonera en Layout.

Por ahora, Botonera también es simplemente un grupo. Esa decisión mantiene visible y comprensible la estructura que acabas de construir.

11. Formación: construir tarjetas manualmente

Ahora vamos a añadir una sección al CV: Formación. Reutilizamos lo que ya sabes; no necesitas aprender nada nuevo todavía.

Titulo-Formacion
├── Fondo
└── FORMACIÓN

Una tarjeta es un bloque visual que reúne información relacionada: formación, proyectos, productos o noticias.

Práctica: primera tarjeta

  1. Crea un rectángulo y renómbralo Fondo.
  2. Crea y nombra los textos: Titulo, Centro, Fechas y Tecnologias.
  3. Escribe: Desarrollo de aplicaciones web; Centro de Formación; 2025 - 2026; HTML · CSS · JavaScript.
  4. Coloca los textos sobre el fondo, selecciónalos y pulsa Ctrl + G.
  5. Renombra el grupo Tarjeta-Formacion.

Qué deberías ver

├── Fondo

├── Centro
├── Fechas
└── Tecnologias

Todos los elementos siguen siendo editables, pero puedes mover la tarjeta completa.

Duplicar y colocar a ojo

  1. Duplica la tarjeta dos veces.
  2. Renómbralas Tarjeta-Formacion-1, -2 y -3.
  3. Cambia sus contenidos a Desarrollo Web, Diseño de interfaces y JavaScript.
  4. Colócalas manualmente, una debajo de otra.

El problema

¿Tienen la misma separación? ¿Qué ocurre al añadir una cuarta? Funciona, pero empieza a ser poco práctico. Ahora sí necesitamos reglas de distribución.

12. Layout: organizar las tarjetas de Formación

Tenemos tres tarjetas colocadas manualmente:

[ Tarjeta 1 ]

  espacio aproximado

[ Tarjeta 2 ]

    otro espacio

[ Tarjeta 3 ]

¿Están realmente separadas igual? ¿Qué ocurre si añadimos otra tarjeta o cambiamos el tamaño de una? Hasta ahora funciona, pero tendríamos que volver a mover elementos.

Penpot puede hacer este trabajo por nosotros mediante Layout. Layout es una forma de decirle cómo queremos que se coloquen los elementos dentro de un contenedor. En lugar de colocar cada elemento uno a uno, definimos unas reglas.

Crear Lista-Formacion

  1. Selecciona las tres tarjetas.
  2. Pulsa Ctrl + G y renombra el grupo Lista-Formacion.
  3. Comprueba en capas que las tarjetas son sus hijas.
  4. Selecciona Lista-Formacion, mira el panel derecho, busca Layout y actívalo.
Lista-Formacion
├── Tarjeta-Formacion-1
├── Tarjeta-Formacion-2
└── Tarjeta-Formacion-3

Las cuatro reglas básicas

Dirección

Indica hacia dónde coloca Penpot los elementos. Para Formación usa vertical: una tarjeta debajo de otra. Horizontal las pondría en una fila.

Gap

Es la separación entre tarjetas. Con gap = 16, Penpot mantiene 16 px entre cada hija.

[ Tarjeta ]

  16 px

[ Tarjeta ]

Padding

Es el espacio interior entre el borde del contenedor y su contenido. Para este primer ejercicio puedes dejarlo en 0.

Alineación

Indica si las tarjetas quedan a la izquierda, centradas o a la derecha dentro de la lista. Elige izquierda para este ejemplo.

Layout no sirve para hacer el diseño más bonito. Sirve para organizarlo mejor.
Primero colocamos elementos. Después definimos reglas.
Gap separa elementos. Padding crea espacio interior.

La prueba importante

  1. Añade Tarjeta-Formacion-4 dentro de Lista-Formacion.
  2. Observa que Penpot la coloca bajo las demás con el mismo gap.

Qué deberías ver

Lista-Formacion
├── Tarjeta-Formacion-1
├── Tarjeta-Formacion-2
├── Tarjeta-Formacion-3
└── Tarjeta-Formacion-4

Todas quedan una debajo de otra, con la misma separación y la alineación elegida.

Si no te sale

No se mueven juntas: comprueba que sean hijas de Lista-Formacion.
La separación es irregular: comprueba que Layout está activo y modifica gap, no las posiciones manuales.
Todo cambia de sitio: no pasa nada; vuelve a dirección vertical, gap sencillo y alineación izquierda.

Grupo frente a Layout

Grupo mantiene las tarjetas juntas, pero sus posiciones siguen siendo manuales.
Layout mantiene las tarjetas juntas y además controla dirección, separación y alineación.

Práctica guiada

Crea tres tarjetas, colócalas manualmente, agrúpalas, activa Layout, elige vertical y gap 16, y añade una cuarta.

Autoevaluación

  1. ¿Qué problema resuelve Layout?
  2. ¿Qué significa dirección?
  3. ¿Qué es gap?
  4. ¿Qué es padding?
  5. ¿Qué diferencia hay entre grupo y Layout?

Tienes cinco tarjetas y quieres la misma separación entre ellas: ¿las colocarías manualmente o usarías Layout? ¿Por qué?

Más adelante, cuando trabajemos con CSS, encontrarás herramientas que organizan elementos siguiendo una idea parecida. Primero domina esto: Grupo organiza. Layout organiza y distribuye.

13. Del móvil al escritorio: diseño responsive

Una pantalla de móvil tiene menos espacio. Por eso responsive no significa hacer desktop más pequeño: significa reorganizar el contenido cuando cambia el espacio.

14. Bibliotecas y plantillas

Primero aprendimos a construirlo nosotros. Ahora podemos reconocerlo, reutilizarlo y adaptarlo. Una biblioteca es una colección de recursos reutilizables: botones, tarjetas, navegación, formularios, iconos, colores, tipografías y otros componentes.

Una biblioteca no sustituye al diseño: nos ayuda a trabajar más rápido.

BibliotecaPlantilla
Conjunto de piezas: Button, Card, Input o Navbar.Diseño o estructura completa: landing page, portfolio, app o dashboard.

Una biblioteca nos da piezas. Una plantilla nos da un punto de partida. Pero ninguna decide por nosotros qué necesita nuestra web.

Añadir una biblioteca

  1. Desde el Dashboard, abre Bibliotecas y plantillas.
  2. Para empezar, elige una Wireframe library o Wireframing kit: sus piezas son sencillas y sirven para practicar botones, tarjetas y navegación.
  3. Añádela al proyecto y vuelve a tu archivo.
  4. Abre RECURSOS y localiza la biblioteca añadida.
  5. Explora sus componentes y arrastra uno sencillo al Board.

Qué deberías ver

WIREFRAMING KIT
├── Components
├── Colors
└── Typography

La estructura exacta puede cambiar según la versión, pero la biblioteca debe aparecer dentro de RECURSOS.

Explorar sin miedo

Prueba un botón, una tarjeta, un campo de formulario y una navegación. Cambia textos o colores si el componente lo permite y compara sus capas con el elemento que construiste manualmente. No necesitas usar todos los componentes en tu CV.

Instancias y personalización

Al arrastrar un componente desde una biblioteca utilizas una instancia. Puede permitir cambiar texto, color, iconos u otros elementos, según cómo se construyó. Despliega sus capas para localizar un icono o SVG y comprobar qué opciones están disponibles.

Si desacoplas una instancia, puedes modificar completamente su estructura, pero deja de estar vinculada al componente original. No necesitas hacerlo en esta práctica.

Si no te sale

El buscador de Bibliotecas compartidas busca bibliotecas disponibles en tu equipo, no en Internet. Si no encuentras una, vuelve al Dashboard y usa Bibliotecas y plantillas.

Sobre Publicar

Publicar no activa una biblioteca que acabas de añadir. Sirve para convertir tu propio archivo —por ejemplo, Biblioteca Curso Web— en una biblioteca reutilizable por otros archivos. Para usar una biblioteca ya añadida no necesitas pulsar Publicar.

Relación con desarrollo: una biblioteca de Penpot contiene piezas para diseñar; Bootstrap contiene piezas para desarrollar. En ambos casos reutilizamos Button, Card o Navbar sin empezar de cero.

Más adelante podrás mirar Design Systems o ejemplos de prototipo. Los tokens, la publicación avanzada y otros sistemas complejos quedan para Para seguir aprendiendo.

Práctica

Añade Wireframe library, abre RECURSOS, arrastra una tarjeta o botón al Board y responde: ¿qué trabajo te ha ahorrado construir desde cero?

15. Nuestro primer prototipo: crear una interacción

Hasta ahora nuestro botón parece un botón, pero todavía no hace nada. Una interacción indica qué debe ocurrir cuando la persona realiza una acción.

usuario hace clic
↓
Penpot ejecuta una acción
↓
aparece otra vista

Tres ideas

Disparador = qué hace el usuario: En click.
Acción = qué hace Penpot: Navegar a.
Destino = a dónde vamos: Proyecto - Detalle.

Un prototipo es una simulación del comportamiento del diseño. Aún no programamos ni existe HTML funcional: probamos la navegación antes de escribir código.

Crear la segunda vista

  1. Mantente en la misma Page de Penpot.
  2. Selecciona Board, crea uno al lado de CV - Mobile y usa un tamaño similar.
  3. Renómbralo Proyecto - Detalle.
  4. Añade solo PROYECTO, nombre, una descripción breve y un grupo Boton-Volver.

Recuerda: 1 Board = 1 vista. No necesitas diseñar esta pantalla en detalle; la finalidad es aprender navegación.

Crear la interacción de ida

  1. Vuelve a CV - Mobile y selecciona el grupo completo Boton-Proyectos, no solo Fondo ni el texto.
  2. Mira el panel derecho y cambia de DISEÑO a PROTOTIPO.
  3. Busca INTERACCIONES y pulsa +.
  4. En Disparador, elige En click.
  5. En Acción, elige Navegar a.
  6. En Destino, elige Proyecto - Detalle.

Qué deberías ver

Boton-Proyectos
↓ En click
↓ Navegar a
Proyecto - Detalle

En el lienzo puede aparecer una conexión visual entre ambos Boards.

Crear VOLVER y probar

  1. En Proyecto - Detalle, selecciona Boton-Volver.
  2. En PROTOTIPO, crea: En click → Navegar a → CV - Mobile.
  3. Localiza Play ▶ y abre la vista previa.
  4. Pulsa PROYECTOS, comprueba el detalle, pulsa VOLVER y comprueba el regreso.

Si no te sale

No aparece INTERACCIONES: selecciona el botón y abre PROTOTIPO.
Destino sin definir: comprueba que existe el Board Proyecto - Detalle.
La interacción está en todo el Board: seleccionaste CV - Mobile; vuelve a seleccionar Boton-Proyectos.
El botón no funciona: comprueba en capas que está dentro de CV - Mobile.

Nota: visualmente PROYECTOS parece un botón; al programar decidiremos qué elemento HTML es adecuado. En Penpot diseñamos la interacción; después implementaremos navegación real.

Práctica

Crea Proyecto - Detalle, conecta PROYECTOS, crea VOLVER y prueba con Play. Reto opcional: repite únicamente En click → Navegar a con un Board Formación - Detalle.

Al terminar debes poder decir: sé crear una segunda vista, seleccionar un botón, definir disparador, acción y destino, y probar mi prototipo.

16. Inspeccionar: el puente entre diseño y desarrollo

Ya sabemos cómo queremos que se vea nuestra web. Ahora necesitamos información para poder reproducirla después con HTML y CSS. Inspeccionar sirve para consultar la información técnica de un elemento del diseño.

Podemos consultar ancho, alto, posición, color, tipografía, espaciados y otras propiedades visuales. No tienes que memorizar valores: lo importante es aprender a encontrarlos.

Entrar en Inspeccionar

  1. Selecciona un elemento de tu CV, por ejemplo Tarjeta-Formacion.
  2. Mira el panel derecho.
  3. Cambia de DISEÑO o PROTOTIPO a INSPECCIONAR.

Qué hace cada pestaña

DISEÑO = modificamos cómo se ve.
PROTOTIPO = definimos qué ocurre al interactuar.
INSPECCIONAR = consultamos información técnica.

Primera práctica: una tarjeta

Selecciona Tarjeta-Formacion y localiza Width (ancho), Height (alto), Left (posición horizontal) y Top (posición vertical).

Estos valores describen dónde está el elemento en el diseño. No significa que debamos escribir exactamente esos mismos valores en CSS.

Texto, color y espaciado

Selecciona el texto FORMACIÓN y observa tipografía, tamaño, peso, color y alineación. Después selecciona Fondo o una tarjeta y observa color de fondo, borde, radio de esquina, ancho y alto.

Penpot también puede mostrar referencias de espaciado entre elementos. Estas medidas ayudan a reproducir la distribución después, igual que el gap y el padding que ya conoces.

Código: una ayuda, no una web terminada

Según la vista y la versión, las herramientas de inspección pueden ofrecer propiedades o fragmentos de CSS, SVG o HTML. Si encuentras Copy as CSS, puedes observar el resultado como ejercicio opcional.

Atención

Penpot puede ayudar a obtener propiedades y fragmentos de código, pero no sustituye el desarrollo. Todavía debemos decidir etiquetas HTML, estructura, accesibilidad, responsive, organización del CSS y comportamiento con JavaScript.

Del diseño al código

Un botón PROYECTOS permite inspeccionar color, tamaño, radio de esquina y tipografía. Después HTML describirá qué es el elemento y CSS cómo se ve. Una Tarjeta-Formacion puede convertirse conceptualmente en una estructura con título y textos; CSS controlará color, espacio, bordes y tamaño.

Qué deberías ver

Al seleccionar texto, tarjeta, imagen, botón o Board desde INSPECCIONAR, cambia la información mostrada. Prueba con todos: cada elemento ofrece propiedades distintas.

Si no te sale

No veo datos: selecciona un elemento y abre INSPECCIONAR.
No veo texto: selecciona directamente su capa, no todo el grupo.
No veo el color: selecciona el elemento que contiene el relleno.
No encuentro código: su ubicación cambia según versión; la práctica principal es consultar propiedades.

18. Para seguir aprendiendo

Has completado la ruta básica. Estos temas son útiles cuando necesites más flexibilidad, pero no son necesarios para crear tu primer CV.

  • Grid Layout: filas y columnas, por ejemplo galerías.
  • Variantes: versiones de un componente, como estados de un botón.
  • Design tokens y sistemas de diseño: reglas reutilizables de color, espacio o tipografía.
  • Inspect: medidas y propiedades como apoyo al desarrollo.
  • Accesibilidad y pruebas UX: contraste, foco, comprensión y uso real.
  • Layouts avanzados: composiciones más complejas cuando domines la base.

Consulta la guía oficial de Penpot cuando uno de estos problemas aparezca en un proyecto real. Así aprenderás cada herramienta cuando tenga un propósito claro.
