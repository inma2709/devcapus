1. Diseñar con IA no es delegar todas las decisiones

Hasta ahora has diseñado interfaces de forma manual en Penpot. Ya conoces páginas, cabeceras, botones, tarjetas, formularios, componentes, filas, columnas, espaciados y jerarquía visual.

Google Stitch es una herramienta de diseño de interfaces asistida por IA. A partir de una descripción escrita puede proponer una interfaz de alta fidelidad. No dibujamos cada elemento uno a uno: explicamos qué queremos construir.

La pregunta importante no es “¿puede la IA hacer una web?”.
Es: “¿sé definir qué debe tener esa web y para qué sirve cada parte?”.
Prompt impreciso

“Hazme una web de veterinaria.”

La IA tendrá que decidir el objetivo, las secciones, los contenidos y la acción principal.

Prompt pensado

Una instrucción con contexto

Indica el público, objetivo, estructura, contenido y estilo. Tú conservas las decisiones de diseño importantes.

3. ¿Qué es un prompt?

Un prompt es la instrucción que damos a una herramienta de inteligencia artificial. Cuanto más claro y útil sea el contexto, más fácil será obtener una propuesta que puedas evaluar y mejorar.

Prompt pobre

“Hazme una web para un gimnasio.”

Prompt pensado como desarrollador/a

“Diseña una landing responsive para un gimnasio dirigido a adultos de 25 a 50 años. Incluye header con navegación y CTA de inscripción, hero, actividades mediante tarjetas, horarios, tarifas, entrenadores, testimonios, formulario y footer.”

Un prompt útil responde, como mínimo, a estas preguntas

  • ¿Qué tipo de página estás diseñando?
  • ¿Para quién está pensada y cuál es su objetivo?
  • ¿Qué secciones debe contener?
  • ¿Qué contenido y acciones son esenciales?
  • ¿Qué estilo visual debe transmitir?

4. Piensa la estructura antes de escribir

Antes de abrir Stitch, organiza mentalmente la página. Por ejemplo, una clínica veterinaria podría necesitar:

Header

Logotipo, Inicio, Servicios, Equipo, Contacto y botón “Pedir cita”.

Hero

Título, texto introductorio, imagen y llamada a la acción.

Servicios

Tarjetas para consulta, vacunación, urgencias o cirugía.

Contacto y footer

Dirección, teléfono, horario, formulario, enlaces legales y redes.

Esta estructura visual se convertirá más adelante en HTML y CSS:

<header>...</header>
<main>
  <section class="hero">...</section>
  <section class="servicios">
    <article>...</article>
    <article>...</article>
  </section>
  <section class="contacto">...</section>
</main>
<footer>...</footer>

5. Ejemplo guiado: HuellaVet

Prueba primero una petición sencilla y observa qué decisiones ha tomado la herramienta. Después utiliza un prompt con requisitos concretos:

Diseña una landing page responsive para una clínica veterinaria llamada HuellaVet.

El público principal son personas que tienen perros y gatos. La página debe transmitir confianza, profesionalidad y cercanía.

Incluye una cabecera con logotipo, Inicio, Servicios, Equipo y Contacto, además de un botón destacado para pedir cita. Crea una sección hero con título, texto, una imagen de una veterinaria atendiendo a un perro y el botón “Pide tu cita”.

Después añade una sección de servicios con cuatro tarjetas: consulta veterinaria, vacunación, cirugía y urgencias. Añade una sección sobre la clínica con imagen y texto, tres opiniones de clientes y una sección de contacto con dirección, teléfono, horario y formulario.

Termina con un footer de contacto, enlaces legales y redes sociales. Utiliza un diseño moderno, limpio y accesible, con colores suaves y buena separación entre elementos.
Compara los resultados.
¿Qué secciones aparecieron porque se las pediste? ¿Qué decisiones dejó la IA en tus manos? ¿Falta una acción importante?

Iterar también es diseñar

No necesitas acertar a la primera. Observa el resultado y usa nuevas instrucciones para mejorarlo:

Claridad

“Haz más visible la llamada a la acción.”

Organización

“Reorganiza los servicios en una cuadrícula de tres columnas.”

Jerarquía

“Reduce el tamaño de la sección principal.”

Simplicidad

“Simplifica el footer y reduce el número de enlaces.”

6. Actividad: diseña tu propia interfaz con Stitch

Reto: no existe un diseño que tengas que copiar. Elige una idea propia: academia, tienda, gimnasio, peluquería, asociación, restaurante, protectora, biblioteca, agencia de viajes, videojuego o portfolio.

  1. Define tu proyecto. Escribe su nombre, tipo de página, objetivo principal y usuario al que se dirige.
  2. Decide sus partes. Haz una lista previa: header, hero, servicios, galería, opiniones, contacto, footer… solo las que tu proyecto necesite.
  3. Escribe el primer prompt. Incluye tipo de web, público, objetivo, secciones, contenido importante y estilo visual.
  4. Genera y analiza. Comprueba si responde al objetivo, si la información está organizada y si se entiende la acción principal.
  5. Mejora el diseño. Realiza al menos tres modificaciones mediante nuevos prompts y explica por qué las has pedido.

Entrega

  • Nombre y descripción breve del proyecto.
  • Lista de secciones elegidas.
  • Prompt inicial y captura del primer resultado.
  • Los tres prompts de mejora.
  • Captura del diseño final.
  • Reflexión: ¿qué cambia entre pedir “hazme una web” y describir exactamente lo que necesitas?
La inteligencia artificial puede generar una interfaz, pero necesita que nosotros sepamos qué interfaz queremos.

Aprender HTML, CSS, diseño y estructura web no pierde importancia al utilizar IA. Al contrario: cuanto más sabes, mejores instrucciones puedes dar y mejor puedes evaluar los resultados.
