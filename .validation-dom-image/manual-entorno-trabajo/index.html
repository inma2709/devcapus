01

Antes de empezar

¿Qué es un entorno de trabajo?

Es el conjunto de elementos que utilizamos para desarrollar nuestros proyectos: el ordenador, el usuario, las carpetas y las herramientas.

Piensa en un carpintero: antes de construir, prepara su mesa, sus herramientas y los materiales. Como desarrolladores, haremos algo parecido con nuestro ordenador.

Durante el curso iremos incorporando nuevas herramientas poco a poco. Hoy solo necesitamos lo esencial.

✦

Hoy necesitamos solamente

  • Windows y nuestro usuario.
  • Una carpeta para los proyectos.
  • Visual Studio Code y el navegador.

02

Tu espacio personal

Crea tu propio usuario en Windows

Tener tu propio usuario es como tener tu propia taquilla: tus archivos y tus ajustes estarán siempre en el mismo lugar.

Qué es

¿Qué es un usuario de Windows?

Es un espacio personal dentro del ordenador. Permite que varias personas usen el mismo equipo manteniendo separados sus archivos, configuraciones y preferencias.

Crear un usuario no crea un ordenador nuevo. Seguimos usando el mismo ordenador, pero cada persona tiene su propio espacio.

05

Nuestra herramienta principal

¿Qué es Visual Studio Code?

Visual Studio Code, habitualmente llamado VS Code, es un editor de código desarrollado por Microsoft.

Un editor es un programa que nos ayuda a escribir y modificar contenido. En este caso, el contenido será código.

IMPORTANTE

VS Code no es un lenguaje de programación. Tampoco crea una web automáticamente. Es la herramienta en la que escribimos y organizamos HTML, CSS y JavaScript.

Microsoft Wordnos ayuda a escribirdocumentos→Visual Studio Codenos ayuda a escribircódigo

Visual Studio Code y Visual Studio no son lo mismo

Nosotros utilizaremos Visual Studio Code. Visual Studio es otro producto de Microsoft orientado a otros tipos de desarrollo. Al descargar, busca exactamente el nombre Visual Studio Code.

Es gratuito, muy utilizado en desarrollo web y funciona con muchos lenguajes. Más adelante podremos ampliarlo con extensiones, pero hoy no las necesitamos.

No. Es un editor de código: la herramienta que utilizamos para escribirlo.

08

Tu primer proyecto

Abre una carpeta y haz una prueba

En desarrollo web trabajamos con carpetas, no con archivos sueltos. Una carpeta reúne todo lo que necesita un proyecto.

¿Qué llamamos proyecto?

Una web no suele ser un solo archivo. Un proyecto reúne todos los archivos relacionados con un mismo trabajo: HTML, CSS, JavaScript, imágenes y otros recursos.

Aún no necesitas conocer la función de cada uno. Lo importante es saber que la carpeta del proyecto los mantiene juntos.

mi-web
├── index.html
├── styles.css
└── imagen.jpg
Archivo → Abrir carpeta

No mueve, copia ni sube la carpeta a Internet. Solo le estás diciendo a VS Code: “Esta es la carpeta del proyecto con el que quiero trabajar”. La misma carpeta que ves en Windows aparecerá en el Explorador de VS Code.

¿Por qué llamamos al archivo index.html?

index.html suele utilizarse como la página inicial de un sitio web. Todavía no estudiaremos HTML: hoy solo vamos a reconocer el nombre.

index+.html

index es el nombre. .html es la extensión, el “apellido” que indica el tipo de archivo. Por ejemplo: foto.jpg, documento.pdf, estilos.css.
