Contenedores y Grid: una cuadrícula hecha con Flexbox

Ya conoces Flexbox, CSS Grid y media queries. Bootstrap no los reemplaza: ofrece una forma preparada de resolver un patrón muy común, columnas responsive para contenido.

Recorrido: 12 unidades · container/row/col · anchuras · responsive · gutters · comparación · prácticas

1. ¿Qué es el Grid de Bootstrap?

Piensa en cada fila como una barra dividida en 12 unidades de anchura. Elegimos qué proporción ocupa cada bloque: 6 + 6, 4 + 4 + 4, 8 + 4 o 3 + 3 + 3 + 3. Las doce unidades no son doce etiquetas obligatorias: son una regla de reparto.

4. Responsive mobile-first: primero móvil

Bootstrap aplica sus clases responsive con min-width: una decisión se conserva desde ese punto hacia arriba. Lee col-12 col-md-6 col-lg-4 como tres decisiones, no como una palabra larga.

  1. Móvil: col-12 = 12/12: una tarjeta por fila.
  2. Desde 768px: col-md-6 = 6/12: dos por fila.
  3. Desde 992px: col-lg-4 = 4/12: tres por fila.
<div class="row g-4">
 <article class="col-12 col-md-6 col-lg-4">...</article>
 <article class="col-12 col-md-6 col-lg-4">...</article>
 <article class="col-12 col-md-6 col-lg-4">...</article>
</div>

5. Separación: gutters

Las columnas llevan padding horizontal y la fila lo compensa para alinearse con el contenedor. Los gutters son ese sistema de separación; recuerdan a gap de Flexbox/Grid, pero no son exactamente el mismo mecanismo.

<div class="row g-4">...</div>   <!-- ambos ejes -->
<div class="row gx-5">...</div>  <!-- solo horizontal -->
<div class="row gy-2">...</div>  <!-- solo vertical -->

6. Bootstrap Grid frente a CSS Grid

En comúnBootstrap GridCSS Grid nativo
Organizan contenido responsive y usan fracciones/proporciones.Patrón de 12 columnas sobre Flexbox; rápido para cards y layouts convencionales.Dos dimensiones: filas, columnas y áreas explícitas.
Ambos conviven.Útil cuando un equipo ya usa Bootstrap o necesitas velocidad/coherencia.Preferible para layouts con áreas, solapamientos o control preciso de filas.

Bootstrap no sustituye CSS Grid. Elige por el problema: tarjetas adaptables y estructura convencional, Bootstrap; distribución bidimensional detallada, CSS Grid.

7. Prácticas progresivas

Ejercicio 1 · Dos columnas

Objetivo: dos bloques a mitad de fila. Parte de una container con una row vacía. Añade dos columnas para “Información” y “Horario”.

<div class="container"><div class="row g-3">
  <!-- añade aquí tus dos columnas -->
</div></div>

Pista: cada bloque necesita 6 de 12. Resultado: dos bloques iguales. Comprueba: cambialos a col-12 col-md-6 para apilarlos en móvil.

Ejercicio 2 · Catálogo responsive

Objetivo: tres cursos: 1 por fila en móvil, 2 en tablet y 3 en escritorio.

<div class="row g-4">
  <article class="card">Curso 1</article>
  <article class="card">Curso 2</article>
  <article class="card">Curso 3</article>
</div>

Instrucción: envuelve cada card en una columna; usa las tres decisiones col-12 col-md-6 col-lg-4. Comprueba: usa el modo dispositivo a 375/768/1280px.

Ejercicio 3 · Contenido + barra lateral

Objetivo: en móvil, contenido y lateral se apilan; desde md, el contenido ocupa 8 unidades y la barra 4.

<div class="container"><div class="row g-4">
 <main><h2>Artículo principal</h2></main>
 <aside>Recursos relacionados</aside>
</div></div>

Pista: ambas piezas empiezan con col-12; desde md, usa col-md-8 y col-md-4. Resultado: lectura prioritaria y lateral proporcional. Error: olvidar las clases base deja dos columnas estrechas en móvil.
