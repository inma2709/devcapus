Bootstrap 5.3: color y personalización

data-bs-theme activa las variables de modo claro u oscuro. Puede ponerse en html o en un contenedor; prueba el componente real, porque no todos los CSS propios cambian automáticamente.

Zona de prueba

El fondo, el texto secundario y controles Bootstrap usan variables de tema.

Abrir recurso →
ActivoOtro
<section data-bs-theme="dark">...</section>
.zona { --bs-primary:#6f42c1; --bs-body-bg:#20123a; }

icon-link organiza icono y enlace; focus-ring añade un foco visible; link-opacity-50-hover cambia opacity en hover; nav-underline crea navegación con subrayado. Son CSS preparado, no JavaScript.

Práctica

  1. Añade data-bs-theme="dark" a una zona de DevAcademy.
  2. Prueba botón, texto secundario, input y card.
  3. Personaliza --bs-primary solo en esa zona.
  4. Comprueba foco y contraste.
