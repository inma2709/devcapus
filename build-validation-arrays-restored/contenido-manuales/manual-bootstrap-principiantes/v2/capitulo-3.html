Utilities: CSS corto, visible y combinable

Una utility es una clase pequeña que aplica una decisión CSS concreta. No es magia ni un lenguaje nuevo: p-3 equivale a un padding predefinido y d-flex activa Flexbox.

1. Cómo leer una utility

La mayoría siguen el patrón propiedad-dirección-tamaño. La familia indica la propiedad, la dirección limita sus lados y el número elige un valor de la escala de Bootstrap.

p-3

Padding en los cuatro lados.

CSS aproximado: padding: 1rem

mt-4

Margin superior.

CSS aproximado: margin-top: 1.5rem

me-auto

Margin-end automática; en una fila LTR empuja lo siguiente hacia la derecha.

CSS: margin-inline-end:auto

Direcciones y escala

  • m/p: margin/padding; t, b, s, e, x, y: arriba, abajo, inicio, final, horizontal y vertical.
  • La escala habitual va de 0 a 5; 0 elimina el espacio y auto usa el cálculo automático de CSS.
  • s y e son preferibles a left/right porque funcionan en diseños RTL.

Lectura responsive: hasta md se apilan; desde 768px se colocan en fila. me-md-auto solo crea el empuje en pantallas medianas o mayores.

3. Display responsive

Las utilities de display permiten mostrar u ocultar elementos sin escribir una media query. La clase sin breakpoint es el comportamiento inicial móvil.

Este aviso aparece desde md (768px).

Este aviso solo aparece por debajo de md.

<p class="d-none d-md-block">Visible desde md</p>
<p class="d-md-none">Visible solo antes de md</p>

No confundas d-none con invisible: el primero retira el elemento del flujo y de las tecnologías de asistencia; el segundo conserva su espacio. Oculta contenido solo cuando no sea esencial.

6. Prácticas progresivas

Práctica guiada

  1. Copia la cabecera anterior.
  2. Cambia p-3 por p-1 y describe el resultado.
  3. Sustituye la alineación por justify-content-center.
  4. Explica qué propiedad CSS representa cada cambio.

Práctica autónoma

Crea una fila de tres tarjetas: en móvil deben apilarse y desde md formar tres columnas. Usa d-flex flex-column flex-md-row, gap-3, border, rounded-3 y una utility de color. No escribas CSS propio.

Solución razonada

<div class="d-flex flex-column flex-md-row gap-3">
  <article class="border rounded-3 p-3 flex-fill bg-light">HTML</article>
  <article class="border rounded-3 p-3 flex-fill bg-primary text-white">CSS</article>
  <article class="border rounded-3 p-3 flex-fill bg-success-subtle">Bootstrap</article>
</div>

flex-fill reparte el espacio disponible; la dirección cambia en md; p-3, border y rounded-3 sustituyen reglas CSS equivalentes.

Errores frecuentes

  • Usar justify-content-between sin d-flex.
  • Escribir margin-right en lugar de me-* y romper RTL.
  • Ocultar información esencial con d-none.
  • Combinar tantas utilities que el HTML deja de ser legible: crea una clase semántica propia.

7. Autoevaluación con respuestas

  1. ¿Qué ocurre con d-none d-lg-block?
    RespuestaEstá oculto por defecto y se muestra desde lg (992px).
  2. ¿Por qué me-auto empuja un botón?
    RespuestaAplica margin en el lado final con valor automático dentro de Flexbox.
  3. ¿Qué cambia entre p-3 y px-3?
    RespuestaEl primero aplica padding en cuatro lados; el segundo solo en horizontal.
  4. ¿Cuándo conviene CSS propio?
    RespuestaCuando expresa una intención reutilizable o no existe una utility adecuada.
