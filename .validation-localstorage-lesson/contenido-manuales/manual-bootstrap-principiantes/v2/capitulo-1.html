Qué es Bootstrap

Un framework CSS es una colección de reglas ya escritas para problemas repetidos: espaciado, rejillas, botones, formularios y componentes. Bootstrap no cambia HTML: button sigue siendo un botón; btn btn-primary son clases que activan reglas CSS preparadas.

CSS propio

.cta { background:#6f42c1; color:white;
padding:.75rem 1rem; border:0; border-radius:.375rem; }

Bootstrap

<button class="btn btn-primary">
  Reservar plaza
</button>

La diferencia no es que Bootstrap “programe” por ti: ahorra volver a escribir una base coherente. Tú decides estructura semántica, textos, imágenes, accesibilidad y estilos de marca.

Cuándo ayuda y cuándo no

SituaciónDecisión razonable
Landing con plazo corto y patrones comunesBootstrap acelera layout y componentes.
Diseño muy singularÚsalo como base y escribe CSS propio, o valora CSS a medida.
Una sola regla puntualNo añadas una dependencia solo por un botón.

Qué archivos cargas

El CSS contiene utilities, grid y aspecto visual. El bundle JavaScript activa componentes interactivos como navbar plegable, dropdown, modal y carousel; incluye Popper. Bootstrap 5 no necesita jQuery.

<head>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css">
  <link rel="stylesheet" href="styles.css"> <!-- tus reglas después -->
</head>
<body>
  <!-- HTML semántico de tu página -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
</body>
Error habitual: cargar styles.css antes de Bootstrap y pensar que la cascada “no funciona”. Tu CSS va después. No uses !important como primera respuesta.

Aprende desarrollo web

Bootstrap aplica estilo; el contenido y su significado son tuyos.

Empezar
<main class="container py-5">
  <h1 class="mb-3">Aprende desarrollo web</h1>
  <p class="text-body-secondary">Tu contenido.</p>
  <a class="btn btn-primary" href="#curso">Empezar</a>
</main>

Práctica progresiva

  1. Crea index.html y pega el enlace CDN de CSS.
  2. Añade un botón sin clases y otro con btn btn-primary.
  3. Abre DevTools, selecciona el segundo y localiza una regla de Bootstrap.
  4. Crea styles.css después del CDN y cambia solo tu color de fondo.

Resultado esperado: el segundo botón tiene padding, color, borde y foco; puedes señalar qué reglas vienen del framework y cuáles escribiste tú.
