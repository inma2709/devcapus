Tema 1 de 6 · 35 min

Descubrir Bootstrap: conectar CSS ya preparado

Al terminar podrás

  • Explicar qué aporta Bootstrap y qué sigue siendo responsabilidad tuya.
  • Conectar el CSS y el bundle de Bootstrap mediante CDN.
  • Reconocer una clase Bootstrap frente a una regla CSS propia.

Bootstrap es una biblioteca de CSS y JavaScript. No crea etiquetas HTML nuevas: añade reglas a clases como btn o btn-primary. Tú sigues eligiendo un button cuando hay una acción y un a cuando hay navegación.

CSS que ya conoces

.cta { background: #6f42c1; color: white;
  padding: .75rem 1rem; border: 0; }

Bootstrap preparado

<button class="btn btn-primary">
  Reservar plaza
</button>

Demostración visual

Micropráctica · El primer botón
  1. Crea un index.html con meta viewport.
  2. Copia el enlace CSS de Bootstrap en head.
  3. Añade un button normal y otro con btn btn-primary.
  4. Inspecciona ambos con DevTools: busca las reglas procedentes de Bootstrap.

Comprobación: el segundo botón tiene color, padding, borde y foco sin que hayas escrito esas reglas.

Consulta: Quick start oficial. El bundle se añade antes de </body> solo si vas a usar componentes interactivos.

Tema 2 de 6 · 65 min

Contenedores y Grid: 12 columnas, no CSS Grid

Al terminar podrás

  • Construir container → row → col.
  • Leer clases responsive mobile-first.
  • Distinguir el sistema de columnas Bootstrap del CSS Grid nativo.

El grid de Bootstrap organiza columnas con Flexbox. CSS Grid sigue siendo la mejor herramienta cuando necesitas controlar filas, áreas y colocación bidimensional. Bootstrap simplifica el patrón habitual de tarjetas responsivas.

<div class="container">
  <div class="row g-4">
    <article class="col-12 col-md-6 col-lg-4">...</article>
  </div>
</div>
col-12 · col-md-6 · col-lg-4
Una card por columna
Mobile-first
Micropráctica · Tres cursos adaptables
  1. Crea una container y una row g-4.
  2. Añade tres columnas col-12 col-md-6 col-lg-4.
  3. Reduce y amplía la ventana: observa 1, 2 y 3 columnas.
  4. Compara la decisión con una media query de min-width.

Comprobación: no hay dos columnas estrechas en móvil y no has escrito una media query.

Tema 3 de 6 · 55 min

Utilities: CSS pequeño, explícito y reutilizable

Al terminar podrás

  • Traducir utilities frecuentes a CSS.
  • Usar espaciado y Flexbox sin convertir el HTML en un catálogo.
  • Elegir cuándo una clase propia comunica mejor la intención.

Una utility resuelve una única propiedad o grupo muy pequeño: d-flex es display:flex; p-3 añade padding. Léela como CSS abreviado, no como una palabra mágica.

d-flexdisplay: flex
justify-content-betweenjustify-content: space-between
p-3padding
mt-4margin-top
FlexboxUtility

Colores, tema y estados sin JavaScript propio

Bootstrap 5.3 usa data-bs-theme para sus modos claro y oscuro. El atributo puede estar en html o en una zona concreta. Comprueba siempre el contraste del componente real que usas.

data-bs-theme="light"

Texto secundario

data-bs-theme="dark"

Texto secundario

primarysuccesswarningdangerinfo

text-primary representa color; text-bg-success combina colores de texto y fondo; opacity-50 cambia opacity; link-opacity-50-hover modifica opacidad al pasar el cursor. border activa borde, rounded-pill aumenta el radio y d-none d-md-block oculta por defecto y muestra desde 768px.

Micropráctica · Una zona oscura sin JavaScript
  1. Copia una section con data-bs-theme="dark".
  2. Dentro, añade una card, un botón y texto secundario.
  3. Elimina el atributo y compara el resultado.
  4. Comprueba texto, fondo y foco con teclado.

Comprobación: el aspecto cambia sin escribir JavaScript; tus clases propias siguen siendo tuyas.

Micropráctica · Cabecera de una tarjeta
  1. Crea un div con título y etiqueta.
  2. Aplica d-flex justify-content-between align-items-center p-3.
  3. Explica qué propiedad CSS representa cada clase.
  4. Si repites el patrón tres veces, crea después una clase propia con un nombre significativo.

Comprobación: título y etiqueta quedan alineados sin CSS nuevo; sabes justificar cada clase.

Tema 5 de 6 · 100 min

Proyecto guiado: landing responsive DevAcademy

Al terminar podrás

  • Montar una landing por incrementos comprobables.
  • Reutilizar grid, utilities y componentes con intención.
  • Preparar E15 como entrega integradora, sin rehacer el trabajo.

No copies una solución completa. Tras cada etapa, guarda, prueba y comprueba antes de avanzar.

  1. Base: crea index.html, conecta Bootstrap, tu styles.css y un main.
  2. Encabezado: adapta una navbar con marca DevAcademy y tres enlaces. Comprueba el menú en móvil.
  3. Hero: añade un mensaje, un CTA y utilities de espaciado. Escribe en CSS propio la altura y el fondo.
  4. Cursos: crea tres cards en row g-4 con col-12 col-md-6 col-lg-4.
  5. Ventajas: usa una fila de tres mensajes breves; no necesitas un componente para todo.
  6. Contacto y footer: añade labels, controles, CTA y enlaces reales.

Comprobación por dispositivo

  • Móvil: menú usable, una columna de cards, CTA visible sin desbordamiento.
  • Tablet: dos cards por fila y espaciado equilibrado.
  • Escritorio: tres cards por fila, líneas de texto legibles y contenido centrado.

Tema 6 de 6 · 40 min

Personalización y comprobación: Bootstrap + tu CSS

Al terminar podrás

  • Cargar CSS propio después de Bootstrap sin abusar de !important.
  • Revisar responsive y estilos con DevTools.
  • Entregar una landing accesible y comprensible.
<link rel="stylesheet" href="bootstrap.min.css">
<link rel="stylesheet" href="styles.css"> <!-- tus decisiones después -->

/* styles.css */
.hero-devacademy { background: #20123a; min-height: 60vh; }
.curso-destacado { border-radius: 1rem; }

Amplía cuando lo necesites

Bootstrap expone variables CSS como --bs-primary o --bs-body-bg. Puedes redefinirlas en tu CSS para una zona concreta. Los modos personalizados son una ampliación: pruébalos componente a componente.

.zona-academia { --bs-primary: #6f42c1; --bs-link-color: #552a9b; }

Guarda patrones repetidos como snippets propios. Para partir de una base, inspecciona y adapta —no pegues sin comprender— Bootstrap Themes, Start Bootstrap y Bootswatch. Comprueba siempre qué versión requiere cada plantilla.

Comprobación final
  • En DevTools, identifica una regla Bootstrap y una regla propia.
  • Prueba a 375 px, 768 px y 1280 px.
  • Recorre con Tab: foco visible, orden lógico, sin trampas.
  • Revisa alt, labels, jerarquía de encabezados y contraste.
  • Explica una decisión en formato: “uso esta clase porque aplica esta propiedad CSS”.

Resultado esperado: tu interfaz mantiene la identidad de DevAcademy y Bootstrap te ha ahorrado trabajo repetitivo, no pensamiento.

Idea que debes conservar: Bootstrap es CSS preparado. Tú sigues diseñando, escribiendo HTML semántico y comprobando que la experiencia funciona.
