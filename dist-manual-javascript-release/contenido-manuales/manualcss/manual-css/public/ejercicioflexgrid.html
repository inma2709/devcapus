PRÁCTICA · FLEXBOX + GRID

Tres ejercicios progresivos para aprender maquetando

En estos ejercicios no vas a memorizar propiedades: vas a utilizarlas para resolver problemas reales de maquetación.

Antes de escribir CSS: identifica siempre el PADRE, sus HIJOS DIRECTOS y decide si necesitas organizar una dirección con Flexbox o filas y columnas con Grid.
  1. Ejercicio 1: una barra de navegación con Flexbox.
  2. Ejercicio 2: una galería de tarjetas con Grid.
  3. Ejercicio 3: una galería Grid cuyas tarjetas contienen un Flex.

EJERCICIO 1 · FLEXBOX

Construye una barra de navegación real

Objetivo: colocar un logotipo a la izquierda y un menú a la derecha. Después utilizarás otro Flexbox dentro del menú para separar sus enlaces.

Resultado que buscamos

┌────────────────────────────────────────────────────────────┐
│ DevCampus                 Inicio  Cursos  Blog  Acceder   │
└────────────────────────────────────────────────────────────┘

HTML de partida

Copia este HTML. No añadas más elementos todavía. 

<header class="cabecera">
  <p class="logo">DevCampus</p>

  <nav class="menu">
    <a href="#">Inicio</a>
    <a href="#">Cursos</a>
    <a href="#">Blog</a>
    <a href="#">Acceder</a>
  </nav>
</header>

Apartado A · Identifica padre e hijos

.cabecera ├── .logo └── .menu

.cabecera es el PADRE. .logo y .menu son sus HIJOS DIRECTOS.

Como queremos colocar esos dos hijos en una misma fila, el padre debe convertirse en contenedor Flex.

Propiedades que necesitas

Propiedad Valor Se aplica a Para qué
display flex PADRE Activa Flexbox.
justify-content space-between PADRE Lleva el primer hijo a un extremo y el último al otro.
align-items center PADRE Alinea verticalmente los hijos.

Construye:

.cabecera {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Apartado B · Convierte el menú en otro contenedor Flex

.menu ├── a ├── a ├── a └── a

Ahora .menu es un HIJO de .cabecera, pero también puede convertirse en PADRE FLEX de sus propios enlaces.

Necesitas:

.menu {
  display: flex;
  gap: 1.5rem;
}
Qué debes observar: gap va en el PADRE porque crea la separación entre todos sus hijos.

Apartado C · Dale aspecto de navegación

Ahora utiliza propiedades que ya conoces para trabajar el aspecto visual. 

.cabecera {
  padding: 1.5rem 2rem;
  background-color: #30343f;
}

.logo {
  color: white;
  font-weight: bold;
}

.menu a {
  color: white;
  text-decoration: none;
}

Apartado D · Comprueba qué hace flex-direction

Cambia temporalmente:

.menu {
  display: flex;
  flex-direction: column;
  gap: 1rem;
}

Observa cómo los enlaces pasan de:

Inicio  Cursos  Blog  Acceder

a:

Inicio
Cursos
Blog
Acceder

Después vuelve a:

flex-direction: row;

Al terminar debes ser capaz de explicar

  • Por qué display: flex se aplica al padre.
  • Qué diferencia hay entre justify-content y align-items.
  • Por qué gap se coloca en el contenedor.
  • Cómo un elemento puede ser hijo Flex y, a la vez, padre Flex.

EJERCICIO 2 · GRID

Construye una sección de tarjetas de cursos

Objetivo: crear una galería de tarjetas distribuida en columnas y hacer que una tarjeta concreta pueda ocupar todo el ancho de la rejilla.

Resultado que buscamos

┌────────────┐ ┌────────────┐ ┌────────────┐
│ HTML       │ │ CSS        │ │ JavaScript │
│ Ver curso  │ │ Ver curso  │ │ Ver curso  │
└────────────┘ └────────────┘ └────────────┘

┌────────────┐ ┌────────────┐ ┌────────────┐
│ React      │ │ Node       │ │ MySQL      │
└────────────┘ └────────────┘ └────────────┘

HTML de partida

<section class="cursos">

  <article class="curso">
    <h2>HTML</h2>
    <p>Estructura tus páginas web.</p>
    <a href="#">Ver curso</a>
  </article>

  <article class="curso">
    <h2>CSS</h2>
    <p>Diseña interfaces atractivas.</p>
    <a href="#">Ver curso</a>
  </article>

  <article class="curso">
    <h2>JavaScript</h2>
    <p>Añade comportamiento a tus páginas.</p>
    <a href="#">Ver curso</a>
  </article>

  <article class="curso">
    <h2>React</h2>
    <p>Crea interfaces mediante componentes.</p>
    <a href="#">Ver curso</a>
  </article>

  <article class="curso">
    <h2>Node</h2>
    <p>Programa JavaScript en el servidor.</p>
    <a href="#">Ver curso</a>
  </article>

  <article class="curso">
    <h2>MySQL</h2>
    <p>Trabaja con bases de datos.</p>
    <a href="#">Ver curso</a>
  </article>

</section>

Apartado A · Identifica el Grid

.cursos ├── .curso ├── .curso ├── .curso ├── .curso ├── .curso └── .curso

El contenedor .cursos es el PADRE GRID. Cada .curso es un HIJO GRID.

Activa Grid:

.cursos {
  display: grid;
}

Apartado B · Crea tres columnas iguales

Necesitas:

grid-template-columns: repeat(3, 1fr);

Significa:

1fr 1fr 1fr
  • repeat → repetir.
  • 3 → tres veces.
  • 1fr → una fracción del espacio disponible.

Añade también:

gap: 2rem;

Tu contenedor debería quedar así:

.cursos {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 2rem;
}

Apartado C · Diseña cada tarjeta

.curso {
  padding: 2rem;
  border: 1px solid #ccc;
  border-radius: 1rem;
  background-color: white;
}
Recuerda box-sizing.
El valor inicial es content-box: si defines un ancho, el padding y el borde se añaden fuera de ese ancho. Para trabajar de forma más previsible es habitual usar: 
* {
  box-sizing: border-box;
}

Ejemplo:

.caja {
  width: 300px;
  padding: 20px;
  border: 2px solid;
}

Con content-box:

300px contenido
+ 40px padding
+  4px border
──────────────
344px reales

Con border-box, el ancho declarado incluye contenido, padding y borde.

Apartado D · Haz que una tarjeta ocupe todo el ancho

Añade una segunda clase a la primera tarjeta: 

<article class="curso destacado">
  ...
</article>

Ahora aplica una propiedad al HIJO GRID:

.destacado {
  grid-column: 1 / -1;
}

1 significa primera línea de Grid y -1 significa última línea.

Observa: grid-template-columns va en el PADRE porque construye la rejilla. grid-column va en un HIJO porque modifica solo esa tarjeta.

Apartado E · Haz la rejilla adaptable

Sustituye:

grid-template-columns: repeat(3, 1fr);

por:

grid-template-columns:
  repeat(auto-fit, minmax(220px, 1fr));
  • minmax(220px, 1fr) → cada columna mide como mínimo 220px y puede crecer.
  • auto-fit → Grid intenta colocar tantas columnas como quepan.

Reduce el ancho del navegador y observa cómo las tarjetas pasan automáticamente de tres columnas a dos y después a una.

Al terminar debes ser capaz de explicar

  • Por qué display: grid va en el padre.
  • Qué significa repeat(3, 1fr).
  • Qué diferencia hay entre grid-template-columns y grid-column.
  • Qué hace auto-fit con minmax().
  • Por qué usamos habitualmente box-sizing: border-box.

EJERCICIO 3 · GRID + FLEXBOX

Construye una galería de productos

Objetivo: utilizar Grid para organizar las tarjetas de producto y Flexbox dentro de cada tarjeta para colocar el precio y el botón de compra.

Resultado que buscamos

┌───────────────────┐ ┌───────────────────┐
│      IMAGEN       │ │      IMAGEN       │
│ Camiseta azul     │ │ Sudadera gris     │
│ Descripción       │ │ Descripción       │
│                   │ │                   │
│ 29,99 €   Comprar │ │ 39,99 €   Comprar │
└───────────────────┘ └───────────────────┘

HTML de partida con placeholders

Para poder realizar el ejercicio sin buscar imágenes todavía, utilizamos imágenes placeholder. Después podrás sustituir cada src por una imagen real. 

<section class="productos">

  <article class="producto">
    <img
      src="https://placehold.co/600x450?text=Camiseta+azul"
      alt="Placeholder de una camiseta azul"
    >

    <h2>Camiseta azul</h2>

    <p>
      Camiseta de algodón disponible en varias tallas.
    </p>

    <div class="acciones">
      <strong>29,99 €</strong>
      <button type="button">Comprar</button>
    </div>
  </article>


  <article class="producto">
    <img
      src="https://placehold.co/600x450?text=Sudadera+gris"
      alt="Placeholder de una sudadera gris"
    >

    <h2>Sudadera gris</h2>

    <p>
      Sudadera cómoda para uso diario.
    </p>

    <div class="acciones">
      <strong>39,99 €</strong>
      <button type="button">Comprar</button>
    </div>
  </article>


  <article class="producto">
    <img
      src="https://placehold.co/600x450?text=Mochila+negra"
      alt="Placeholder de una mochila negra"
    >

    <h2>Mochila negra</h2>

    <p>
      Mochila ligera con varios compartimentos.
    </p>

    <div class="acciones">
      <strong>24,99 €</strong>
      <button type="button">Comprar</button>
    </div>
  </article>

</section>

Apartado A · Construye el Grid exterior

.productos ├── .producto ├── .producto └── .producto

.productos será el PADRE GRID. 

.productos {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(250px, 1fr));
  gap: 2rem;
}

Apartado B · Diseña las tarjetas

* {
  box-sizing: border-box;
}

.producto {
  padding: 1.5rem;
  border: 1px solid #ddd;
  border-radius: 1rem;
  background-color: white;
}
Qué estás haciendo: Grid controla la posición de las tarjetas. El borde, padding y fondo solo trabajan el aspecto de cada tarjeta.

Apartado C · Haz que todas las imágenes tengan la misma proporción

.producto img {
  display: block;
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
}

aspect-ratio: 4 / 3

Indica la proporción que debe mantener la caja de la imagen: por cada 4 unidades de ancho tendrá 3 de alto.

object-fit: cover

Hace que la imagen llene completamente esa caja sin deformarse. Si sobra parte de la imagen, se recorta.

No confundas: aspect-ratio define la forma de la caja; object-fit decide cómo se adapta la imagen dentro de ella.

Apartado D · Encuentra ahora el Flexbox

Dentro de cada tarjeta tenemos:

<div class="acciones">
  <strong>29,99 €</strong>
  <button type="button">Comprar</button>
</div>
.acciones ├── strong └── button

Queremos colocar precio y botón en una sola fila. Por tanto, .acciones será un PADRE FLEX. 

.acciones {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Resultado:

29,99 €                              Comprar

Apartado E · Analiza toda la jerarquía

.productos → PADRE GRID │ ├── .producto → HIJO GRID │ │ │ ├── img │ ├── h2 │ ├── p │ │ │ └── .acciones → PADRE FLEX │ ├── strong → HIJO FLEX │ └── button → HIJO FLEX │ ├── .producto → HIJO GRID └── .producto → HIJO GRID
Idea fundamental: un elemento puede ser hijo de un Grid y, dentro de él, contener otro elemento que se convierta en padre Flex.

Apartado F · Reto práctico

  1. Añade un cuarto producto copiando la estructura de una tarjeta y cambia su título, descripción, precio e imagen placeholder.
  2. Reduce el ancho del navegador y comprueba cómo Grid cambia automáticamente el número de columnas.
  3. Cambia temporalmente justify-content: space-between por center dentro de .acciones y observa la diferencia.
  4. Añade gap: 1rem a .acciones. Comprueba cómo Flexbox mantiene una separación mínima entre precio y botón.

Propiedades necesarias en este ejercicio

Propiedad Valor utilizado Se aplica a Para qué
display grid PADRE GRID Activa Grid.
grid-template-columns repeat(auto-fit, minmax(250px, 1fr)) PADRE GRID Crea columnas adaptables.
gap 2rem PADRE GRID Separa las tarjetas.
box-sizing border-box Todas las cajas Hace más previsible el cálculo del tamaño.
aspect-ratio 4 / 3 Imagen Mantiene una proporción común.
object-fit cover Imagen Rellena la caja sin deformar la imagen.
display flex PADRE FLEX Activa Flexbox dentro de la tarjeta.
justify-content space-between PADRE FLEX Separa precio y botón hacia los extremos.
align-items center PADRE FLEX Alinea precio y botón verticalmente.

Al terminar debes ser capaz de explicar

  • Por qué el contenedor exterior utiliza Grid.
  • Por qué .acciones utiliza Flexbox.
  • Cómo puede combinarse Grid con Flexbox en una página real.
  • Qué diferencia existe entre propiedades del padre y propiedades de sus hijos.
  • Qué hacen aspect-ratio y object-fit.
