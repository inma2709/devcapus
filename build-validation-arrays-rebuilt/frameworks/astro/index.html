Astro: de HTML a componentes

Aprende a organizar HTML, CSS y JavaScript para construir sitios web más fáciles de mantener.

Cuando diez páginas repiten menú y footer, un cambio obliga a editarlo diez veces. Astro permite crear esas piezas una vez y reutilizarlas. También puede generar HTML listo para mostrar, evitando JavaScript innecesario cuando no aporta valor.

Qué aprenderás

  • Comprender Astro: qué aporta y cuándo usarlo.
  • Crear un proyecto: instalación, servidor y carpetas.
  • Reutilizar componentes: Navbar y Footer sin repetir HTML.
  • Trabajar con layouts: estructura compartida y <slot />.
  • Construir una web: páginas conectadas y estilos comunes.

Tu proyecto final: Lumen Studio

Construirás una web corporativa con Inicio, Servicios y Contacto. Al modificar Navbar.astro, Footer.astro o BaseLayout.astro, los cambios se reflejarán de forma coherente en todo el sitio.

Cómo utilizar este manual

  1. Lee antes de copiar código.
  2. Escribe el ejemplo y comprueba el navegador.
  3. Intenta los ejercicios antes de abrir la solución.
  4. Ante un error, revisa ruta, código y terminal.
  5. No avances hasta completar el paso anterior.

Necesitas HTML semántico, CSS y JavaScript básico. No necesitas conocer Astro, React ni backend.
